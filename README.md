# Discrete-components-audio-amplifier
Stereo 2 x 60W, fully analog, AB-class, fully discrete audio amplifier with audio jack input and Bluetooth support.
THIS PCB CAN BE DEADLY AS IT USES HIGH VOLTAGES AND POWER. BE SURE TO KNOW WHAT YOU ARE DOING IF YOU BUILD IT!!

All the schematics were simulated in LTSpice and ported to KiCAD for the PCB design.
Simulated and designed by Francesco B. Tocci and Matteo Mattia, electronics engineering students
at Sapienza University of Rome.
The whole project was made just for fun and is now aviable for all of you.
To date, the amplifier has never been phisically built, so it may contain some mistakes. It's provided "as is".

In detail, the project consists of a circuit that includes:
  -A 200W analog power supply
  -Two 60W AB-class audio amplifiers featuring overcurrent protection
  -Pins to attach a standard and widely aviable Bluetooth module
  -Volume control, 3.5mm audio jack input, Bluetooth push button and speakers power output.

Other than the PCB and it's components, to use the amplifier you'll also need:
  -Two heatsinks, to be placed on both sides right where the power transistors face towards the PCB outline
  -A 220V (or whatever is standard in your country) to +28V 0V -28V (dual output) toroidal transformer
  -A grounded metal base plane, so that all the mounting screws provide secure grounding to the components
  -An MH-M18 Bluetooth module (such as https://amzn.eu/d/1KDv10z)
  -A 220V to 5VDC power supply (such as https://amzn.eu/d/5lVEZ71)
  -An enclosure, if you wish.

In this repository you'll find all the files needed for production or further developing, and also some screenshots.
Thank for your interest!
